### 1.2 已实现且基本对齐需求的部分

- MTL RX/TX 双口初始化、组播、PTP 读取、DRM 多 plane compositor 复用 RK3588 链路。TX 通过 `tx_session` 做参数校验与状态机，角色互斥在引擎侧保证，数据面由 `tx_backend_live_ingest` 承接。
- 单节点多窗口：`rx_compositor` 最多 8 路 lane（V1 NV12 实际 4 路），几何变化走 `try_fast_apply` 快速路径，其余重建。
- IPC 两阶段加扩展动词：`hello/configure/set_sources/prepare/commit/abort/clear/query_state/capability/tx_start/tx_stop/event`；`commit/clear` 走单槽串行执行器，`prepare` 走异步 worker；同 uid peer 鉴权、按连接 `requestId` 重放缓存。
- revision 幂等与并发保护：stale 拒绝、commit-before-prepare 拒绝、并发 operation 拒绝、已提交重放直接返回。
- 白名单准入与 LRU：`whitelist + 8-slot LRU`，命中刷新、满时淘汰最久未用；代理与引擎桥两侧均做逐项地址/端口校验，非法项直接报参数错误。
- 音量：可调 ALSA Master 音量；`audioOwner` 取扇出顺序中最新未静音窗口透传，引擎仅保存 owner/volume 并在 commit 后应用。
- 能力探测（部分真实）：DRM connector/mode/plane 数、V4L2 采集口枚举真实；`max_layers` 来自 plane 数；`max_decode_sessions` 暂为固定值加 env 覆盖；`ptp/mtl` 初始为未知，有 MTL 句柄时刷新。
- 节点注册、心跳、离线判定、墓碑：代理侧 3 次心跳失败判离线、auto/manual 注册；平台侧 WS 心跳与 barrier ack、注册时墓碑拦截、`retire` 写墓碑并删节点、墓碑 GC。
- 节点本机配置 scope 与 desired/applied revision，`pendingRole` 延迟激活，重启路径提升角色并清媒体。
- 工厂重置保留网络与注册并清媒体；升级做 SHA256 校验与分版本 staging，失败保留旧版，真实切换保持门控。
- 幂等键缓存、审计日志、tombstone GC。
- `OpCoordinator` 不止于描述：prepare barrier、缺员集合、超时清扫、rollback 标记可重放、已提交快照供回滚重发均已实现，且平台已真实扇出。
- 布局拆分数学：`layout_cell_grid`、`fragment_for_node`（按节点几何裁扇出窗口并组装该节点所需信号端点表）、`layout_apply_at_ns`。原表中的 `layout_window_fragment` 为误记，实际函数名为 `fragment_for_node`。

### 1.3 主要未实现 / 仅占位

- 平台业务规则校验仍缺：分组删除前墙计数与名称唯一、拼墙生命周期与软删除语义、端口空闲与离线 pending、组播地址池分配与端口唯一性、编码参数与绑定约束。白名单端点组装（信号、地址、端口、模式）与按节点拆分已通，缺的是规则层拒绝。
- 场景快照、未保存改动比较、默认场景、生效场景保护仍缺。
- 媒体 prepare 期真实资源预留仍缺：当前 prepare 只做校验与影子布局暂存加短暂模拟等待，组播加入、RX 会话、首帧解码、plane 预分配发生在 commit 阶段的重建中。
- 跨格源裁剪未生效：`pip_stream` 的源裁剪字段、解析与 lane 比较已存在，DRM 渲染仍按全帧送显，未使用裁剪起点。
- 音频归属与路由：仅 Master 音量，无窗口级仲裁与跟随切换验证。
- 底图按格拆分与下发仍缺。
- 同帧提交：影子布局暂存、abort/clear 回退、按目标时间等待已有，缺 VSYNC/vblank 原子 plane 切换与失败回滚。
- 时钟资格判定仍缺：仅有 PTP 读取（同步与否加固定偏移），平台无整墙拦截逻辑。
- 计数真实性：`query_state` 的会话、解码、图层数为布局回显，lane 明细、PTP、TX 快照已接真引擎，但解码健康与丢包仍非实测。
- SIP 仅连通性探测，无完整会话；固件真实切换保持门控；网络系统应用默认不执行，需隔离环境加显式 env。
- 播放任务八态机与节点当前播放投影仍缺。
