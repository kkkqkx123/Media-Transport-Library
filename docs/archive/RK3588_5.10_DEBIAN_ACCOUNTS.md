# RK3588 5.10 Debian(XFCE) 镜像账户与登录信息

> 归档：2026-10-29。对象是 `devs:/data/kkkqkx/rk3588_5.1_XDP` 用 `./build.sh debian` 生成的
> Debian bullseye XFCE rootfs（`debian/linaro-rootfs.img`，3.7 GB）。
> 目的：留档**可用的登录凭据**

Debian 让 ssh 可以直接登录 root ：
ssh linaro@192.168.80.202，密码linaro【普通用户登录】
sudo passwd root，密码123456
sudo vim /etc/ssh/sshd_config
PermitRootLogin yes
sudo systemctl restart sshd

---

## 1. 结论

| 账户 | 密码 | 权限 | 说明 |
|---|---|---|---|
| `linaro`（uid/gid 1000） | **`linaro`** | 在 `sudo` 组（`sudo:x:27:linaro`），`sudo` **需要密码** | 桌面登录用这个；`sudo -i` 提权 |
| `root` | **无可用密码（锁定）** | — | `/etc/shadow` 里是 `root:*`，即 `*` 表示禁止密码登录；`su` / 串口登录 root 都不行 |

改密码（在板子上，用 linaro 登录后）：

```bash
sudo passwd linaro        # 改普通用户
sudo passwd root          # 若确实需要 root 直接登录，先解锁再设密码
```

## 2. 证据

### 2.1 `/etc/shadow`（取自 base tarball 与最终 rootfs，两者一致）

```
root:*:20754:0:99999:7:::
linaro:$y$j9T$OAb06gcQJY0ETWpl571tW.$MBCZidKtVnfgEw2XQggJCb3Lns.vsNVZwalmxQYnlq5:20754:0:99999:7:::
```

- `root:*` → 密码字段为 `*`，**账户被禁止用密码登录**。
- `linaro:$y$...` → **yescrypt** 哈希（`$y$`），不是旧的 `$6$`。校验方式：在 bullseye rootfs 里用
  `python3 -c "import crypt; crypt.crypt('linaro', '<该 hash>')"` 比对，结果为**完全一致** → 密码就是 `linaro`。

### 2.2 其它相关配置

| 项 | 值 | 来源 |
|---|---|---|
| `linaro` 所属组 | `sudo` | `binary/etc/group`: `sudo:x:27:linaro` |
| `sudoers.d` | 只有 `README`（**没有** `NOPASSWD` 配置） | `binary/etc/sudoers.d/` |
| `lightdm` 自动登录 | `lightdm.conf` 里 `autologin-user` 等**全部是注释**，未启用 | `binary/etc/lightdm/lightdm.conf` |
| 串口 getty | `mk-rootfs-bullseye.sh` 把 `serial-getty@.service` 的 `ExecStart` 改成 `-/bin/sh -c '/bin/bash -l </dev/%I >/dev/%I 2>&1'`，**串口上免密进 root shell** | `debian/mk-rootfs-bullseye.sh`（`# enter root username without password`） |

> 也就是说：**HDMI/桌面**要 `linaro`/`linaro` 登录；**串口**（ttyS3）是免登录 root shell，不需要密码。

### 2.3 密码不是本仓库的脚本设的

`debian/mk-rootfs-bullseye.sh` 里没有任何 `chpasswd` / `passwd` 调用（只有上面那处 serial-getty 改动）。
`linaro` 的密码来自 base tarball，即 live-build 阶段：

```
debian/mk-base-debian.sh
  → RELEASE=bullseye TARGET=xfce ARCH=arm64
  → debian/ubuntu-build-service/bullseye-xfce-arm64/   (lb config + lb build)
  → linaro-bullseye-alip-YYYYMMDD-1.tar.gz
```

所以换 `TARGET`（desktop / gnome / lxde）不改变默认密码；要改默认密码得在
`ubuntu-build-service/bullseye-xfce-arm64/customization/` 里加 hook，或打包后 `sudo passwd`。
