# DVS P1–P3 剩余缺口清单

> 基准：当前工作树；状态以 `docs/plan/dvs/BACKEND_STATUS_AND_REMAINING_TASKS.md` 为准。
> 范围：P1 单节点多路热更新、P2 两节点墙闭环、P3 同帧与跨格切换。
> 本清单只列缺口，不重复已实现项。

## 1. 功能缺口

### P1 媒体引擎

- 音频归属与路由未完成：当前仅 Master 音量与 owner 保存，窗口级仲裁、跟随切换与静音策略未落地。
- 跨格源裁剪未生效：拆分数学与 lane 字段已存在，但 DRM 渲染仍按全帧送显，未使用源裁剪起点。
- 能力配额未真实化：`maxDecodeSessions` 仍为固定值加环境覆盖，PTP 偏移与 MTL/backend 状态需真实刷新。
- `query_state` 健康计数未真实化：解码健康、lane 丢包仍部分为布局回显，不是实测值。
- Input 角色 teardown 未完整：V4L2/RGA/MPP/MTL TX 资源释放、幂等保护与能力门控仍需补齐。
- 角色切换往返路径未形成稳定闭环：`output -> input -> output` 的资源释放、残留 plane 检查与泄漏检查仍待实现。

### P2 平台控制面

- 业务规则校验仍缺：分组名称唯一、拼墙生命周期与软删除语义、端口空闲与离线 pending、组播地址池分配与端口唯一性、编码参数与绑定约束。
- 场景管理未完成：场景快照、未保存改动比较、默认场景、生效场景保护仍缺。
- 底图处理未完成：底图按格位并集拆分子图并下发、清屏后仅留底图尚未实现。
- 媒体 prepare 真实资源预留未实现：当前 prepare 仅做校验、白名单准入与影子布局暂存，组播加入、RX 会话、首帧解码、plane 预分配尚未在 prepare 阶段完成。
- 节点运维联动未完成：角色切换与平台清理、热插拔与 EDID 事件、网络系统应用默认语义仍需收尾。

### P3 同帧与跨格

- 帧边界原子切换未实现：当前提交路径仍可能重建合成器/解码器，未达到仅切 plane 属性的 VSYNC/vblank 原子切换。
- 时钟资格判定未实现：平台侧尚无 PTP synced、偏差阈值、帧号一致、解码就绪、节点在线的整墙拦截逻辑。
- 跨格源裁剪未生效：窗口交集拆分已实现，但渲染侧未消费源裁剪字段。
- 失败 rollback 的渲染恢复未完全闭环：rollback 描述与重放框架已有，但原子恢复与画面一致性仍待实现。
- 大规模/长稳能力未验证：128 节点、4×4 墙、24h 稳定运行仍未覆盖。

## 2. 验证缺口

### P1 验证

- 单板单节点 4 路 1080p60 合成显示未验证。
- 单节点窗口移动、缩放、调层序热更新未在 RK3588 上实测。
- 单路动态换源不闪断未实测。
- Input 角色出流与 output/input/output 往返切换未在单板验证。
- 能力上报与 `query_state` 计数真实性未在单板比对。

### P2 验证

- 两节点 2×1 墙端到端闭环未在真实节点上走通。
- 建组、建墙、绑定、白名单、开窗、存场景的完整流程未端到端验证。
- 平台扇出、barrier 聚合、rollback 重发未在两节点真实链路验证。
- 布局像素拆分与跨格窗口接缝未在真实显示上验证。

### P3 验证

- 2×2 墙 1000 次切换的偏差 ≤1 帧未实测。
- 离线节点导致整墙 blocked 的行为未在真实节点上验证。
- commit 失败自动 rollback 的画面一致性未实测。
- PTP 域下多节点帧号一致与偏差阈值未实测。
- 媒体引擎重启 30 秒内恢复最后布局、断控制网络 30 分钟画面不黑未验证。
