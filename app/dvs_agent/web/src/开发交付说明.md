# 节点设备后台 · 交付说明

本包为节点设备后台（单机本机页），通过本地 dvs-agent HTTP 服务 (`/api/v1/...`) 读取与修改节点真实状态。平台 Web 后台页面不包含在本包内。

## 运行

节点 agent 启动时指定 Web 根目录，例如：

```bash
./dvs_agent --web-root ./web/src --port 8080
```

浏览器访问 `http://<节点IP>:8080/`。登录账号由节点本地存储初始化（默认 `admin`，首次登录强制修改密码）。

## 说明

- 页面源码：`packs/node-admin/node-admin.html`。
- `_shared/` 包含真实 API 适配器与公共样式；`vendor/` 包含 TDesign 资源；`assets/` 包含品牌资源。
- 节点信息、配置状态机、维护操作、媒体状态均来自 dvs-agent；无浏览器本地真源。
- 认证使用 HttpOnly Cookie 会话 + PBKDF2 密码校验 + 登录限速；生产环境建议启用 `DVS_REQUIRE_AUTH=1`。
