# 节点设备后台 · 开发交付

本包为节点设备后台的可交互前端原型，包括设备配置（节点角色、输入口、输出设置、网络与注册）、播放执行（播放任务）和查看与维护（本机信息、维护操作）。平台 Web 后台页面不包含在本包内。

## 运行

安装 Node.js 20.11 或更高版本，在解压后的 `node-device-admin` 目录执行：

```bash
npm start
```

浏览器访问 `http://localhost:4173/`。无需安装 npm 依赖。端口被占用时可设置 `PORT` 环境变量。局域网访问需使用运行机器的局域网 IP，且网络和防火墙允许连接。

演示登录账号为 `admin`，密码为 `admin123`。仅用于本地原型演示，不能作为生产环境身份认证。

## 开发说明

- 页面源码：`packs/node-admin/node-admin.html`。
- `_shared/` 包含节点状态、播放任务、模拟接口和公共样式；`vendor/` 包含 TDesign 资源；`assets/` 包含品牌资源。
- 节点、配置和播放任务为浏览器本地模拟数据。不同浏览器或访问地址的数据不互通；实际设备配置、注册、播放、重启和升级需要对接真实接口及设备回执。
- 登录、密码与设备维护操作均为演示逻辑，不具备生产安全能力；请在开发接入时实现真实认证、权限和服务端校验。
